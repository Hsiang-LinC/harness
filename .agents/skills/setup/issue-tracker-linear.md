## Pull requests

A PR is not a work item. Linear's GitHub integration links a PR to the issues it delivers, code and document PRs alike, when the PR body says:

`Closes <issue>`

A branch name that contains the issue key links the PR the same way. `Part of <issue>` links a PR that contributes to an issue without delivering it.

## Wayfinding

Used by `/wayfinder`: the map is an issue labelled `wayfinder:map`; its child works are labelled `wayfinder:<type>`. The labels are mapped in `triage-labels.md`.
